## Overview
**Beat the Mess Rush** is a responsive web and mobile prototype designed for Lovely Professional University (LPU) campus messes to address peak-hour queue bottlenecks, lack of crowd visibility before leaving hostels, and plate food wastage caused by fixed serving portions.

## Core Prototype Features
* **Splash & Onboarding:** LPU-branded entry screen introducing Smart Crowd & Food Management.
* **Home Dashboard:** Quick navigation across Live Crowd, Food Refill, My History, Feedback, and Profile & Settings.
* **Live Crowd Dashboard:** Switch between **Own Hostel Mess** and **Central Mess**, view simulated peak-hour status (`DEMO DATA` badge), estimated wait time, and color threshold legend (`Green <5m | Yellow 5–12m | Red >12m`).
* **Food Refill Request & Status:** Select mess location and choose **Half Portion** (recommended to reduce food waste) or **Full Portion**, with instant refill confirmation (`~4 mins`).
* **Refill History, Feedback & Profile:** Tracks monthly refill count, allows star ratings and suggestions, and provides alert/theme/language preferences.
* **Cross-Device Support:** Built as a standalone, responsive `index.html` file that works on both mobile phones and laptops.
